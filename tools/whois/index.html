About WHOIS:

  • WHOIS is a protocol used to query databases that store registered users or assignees of domain names and IP addresses
  • WHOIS information typically includes registration dates, owner contact info, name servers, and status
  • Due to GDPR, many WHOIS records now show redacted contact information
  • Different TLDs (like .com, .org, .net) have different WHOIS servers
  • IP WHOIS shows information about IP address allocations
