How to use the Online Compiler:

  • Select your programming language from the dropdown
  • Write or paste your code in the editor
  • Provide any required input in the STDIN field
  • Click "Run Code" to execute your program
  • View the output in the results section
  • Use "Share" to generate a link to your code

Supported Languages:

  • Python (3.x)
  • JavaScript (Node.js)
  • Java (OpenJDK)
  • C (GCC)
  • C++ (G++)
  • C# (Mono)
  • PHP
  • Ruby
  • Go
  • Swift

Code execution happens on secure servers - your code is not stored permanently
