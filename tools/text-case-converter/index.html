How to use this Text Case Converter:

  • Enter your text in the input box

  • Copy the converted text to clipboard

Case Styles Explained:

  • lowercase: all letters in small case (example)
  • UPPERCASE: ALL LETTERS IN CAPITAL CASE (EXAMPLE)
  • Title Case: First Letter Of Each Word Capitalized
  • Sentence case: First letter of first word capitalized
  • camelCase: firstWordLowerCaseThenCapitalized
  • PascalCase: EachWordCapitalizedNoSpaces
  • snake_case: words_separated_by_underscores
  • kebab-case: words-separated-by-hyphens

All processing is done in your browser - your text never leaves your computer
