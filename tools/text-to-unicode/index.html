How to use this converter:

  • Text to Unicode:
    • Enter text in the input field
    • Select the desired output format
    • Click Convert to generate Unicode representations
  • Unicode to Text:
    • Enter Unicode code points, escape sequences, or hex values
    • Select the matching input format
    • Click Convert to decode to text
  • View detailed information about each character in the table
  • Copy results to clipboard as needed

About Unicode:

  • Code Points: Unique numbers assigned to each character (U+0000 to U+10FFFF)
  • UTF-8: Variable-width encoding (1-4 bytes) compatible with ASCII
  • UTF-16: Uses 2 or 4 bytes per character
  • UTF-32: Fixed 4-byte encoding for each character
  • Planes: Unicode is divided into 17 planes (Basic Multilingual Plane is U+0000-U+FFFF)
  • Emoji: Modern emoji are typically in the Supplementary Multilingual Plane

All conversion happens locally in your browser - no text is sent to any server
