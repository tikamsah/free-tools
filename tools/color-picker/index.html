Color Formats Explained:

  • HEX: Hexadecimal format (e.g. #3B82F6) - used in web design
  • RGB: Red, Green, Blue (e.g. rgb(59, 130, 246)) - screen colors
  • HSL: Hue, Saturation, Lightness (e.g. hsl(217, 92%, 60%)) - human-friendly
  • CMYK: Cyan, Magenta, Yellow, Key (e.g. cmyk(76%, 47%, 0%, 4%)) - for print

All processing is done in your browser - no data is sent to any server
