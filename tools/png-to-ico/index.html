How to use this converter:

  • Upload a PNG image (transparency is supported)
  • Select the sizes you want to include in your ICO file
  • Click Convert to ICO to generate the file
  • Download the ICO file for your website or application

ICO File Information:

  • ICO files can contain multiple image sizes in one file
  • Windows selects the best size automatically
  • Recommended sizes: 16×16, 32×32, 48×48 (for Windows applications)
  • For favicons: 16×16, 32×32 (browser favorites), 64×64 (desktop shortcuts)
  • Larger sizes (128×128, 256×256) are useful for high-DPI displays

HTML Implementation:

  • Standard favicon: <link rel="icon" href="/favicon.ico" type="image/x-icon">
  • For modern browsers: <link rel="icon" href="/favicon.ico" sizes="any">
  • For IE 11 and below: <link rel="shortcut icon" href="/favicon.ico">

All processing is done in your browser - your images never leave your computer
