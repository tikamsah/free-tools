How to use this SQL Query Builder:

  • Select the type of query you want to build (SELECT, INSERT, UPDATE, DELETE)
  • Choose the table you want to query
  • Select columns for SELECT queries or enter values for INSERT/UPDATE
  • Add conditions to filter your results
  • Set additional options like LIMIT, ORDER BY
  • Click Generate SQL to create your query

SQL Query Examples:

  • Basic SELECT: SELECT id, name FROM users WHERE active = 1
  • INSERT: INSERT INTO products (name, price) VALUES ('Widget', 19.99)
  • UPDATE: UPDATE customers SET email = 'new@example.com' WHERE id = 42
  • DELETE: DELETE FROM orders WHERE status = 'cancelled'

All processing is done in your browser - your data never leaves your computer
