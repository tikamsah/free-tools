About DNS Records:

  • A: Maps a domain to an IPv4 address
  • AAAA: Maps a domain to an IPv6 address
  • CNAME: Canonical name record (alias of another domain)
  • MX: Mail exchange record for email routing
  • TXT: Text record often used for verification
  • NS: Nameserver records for the domain
  • SOA: Start of Authority record with admin info
  • PTR: Pointer record for reverse DNS lookups

DNS queries are performed using Google's public DNS-over-HTTPS service
