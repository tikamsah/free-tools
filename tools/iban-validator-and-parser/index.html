How to use this validator:

  • Enter an IBAN in the input field (with or without spaces)
  • Click Validate & Parse to check the IBAN
  • View validation results and parsed details
  • Use Load Sample to test with example IBANs
  • Results include country, bank code, branch code, and account number

About IBAN:

  • Structure: Country code (2 letters) + Check digits (2 numbers) + BBAN (up to 30 chars)
  • Purpose: Standardized international bank account identification
  • Validation: Includes checksum verification and length check
  • Countries: Supports all IBAN countries with proper formatting
  • Formatting: Typically presented in groups of 4 characters

All processing happens locally in your browser - no IBANs are sent to any server
