How to use this Color Converter:

  • Select the input color format (HEX, RGB, HSL, or CMYK)
  • Enter your color values in the appropriate fields or use the color picker
  • Click Convert to see the color in all formats
  • Preview the color and explore color schemes
  • Click the eyedropper icon on any color to apply it
  • Copy any format to clipboard with the copy buttons

Color Formats Explained:

  • HEX: #RRGGBB format (hexadecimal values for red, green, blue)
  • RGB: Red, Green, Blue values (0-255 each)
  • HSL: Hue (0-360), Saturation (0-100%), Lightness (0-100%)
  • CMYK: Cyan, Magenta, Yellow, Black percentages (0-100% each)
