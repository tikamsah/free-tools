How to use the String Utilities:

  • Case Converter: Change text between different case formats (uppercase, lowercase, title case, etc.)
  • Encode/Decode: Convert text between different encoding formats (URL, Base64, HTML, Hex)
  • Formatting: Clean and format text by trimming, reversing, removing elements, etc.
  • Text Analysis: Get statistics and insights about your text (character count, word count, etc.)
  • All processing happens in your browser - your data never leaves your computer
