How to use this converter:

  • Paste your Base64 string in the input area
  • Click Decode Base64 to convert to an image
  • Preview the image and check its format
  • Download the image in its original format

Supported Formats:

  • Base64 strings with data URI prefix (data:image/png;base64,...)
  • Raw Base64 strings (without data URI prefix)
  • Output formats: PNG, JPG, GIF, WEBP, etc.

All processing is done in your browser - your data never leaves your computer
