How to use this IP Lookup Tool:

  • Enter the IP address you want to lookup in the input field
  • Click Lookup IP to retrieve detailed information
  • Click My IP to see information about your current IP address
  • View the returned information in the results section
  • Copy the information or clear the results as needed

About IP Addresses:

  • An IP address is a unique identifier for devices on a network
  • IPv4 addresses look like 192.168.1.1 (32-bit)
  • IPv6 addresses look like 2001:0db8:85a3::8a2e:0370:7334 (128-bit)
  • Public IPs identify your device on the internet
  • Private IPs identify devices on local networks

All lookups are performed using third-party APIs. We don't store your IP address or lookup history.
