About User Agent Strings:

  • A user agent string identifies your browser and operating system to web servers
  • Contains information about browser name, version, rendering engine, and device
  • Used by websites to deliver content optimized for specific browsers or devices
  • Format varies between browsers but typically includes browser name, version, and platform
  • Can be spoofed or modified by browsers for privacy or compatibility reasons

All parsing is done in your browser - we never store or log your user agent information
