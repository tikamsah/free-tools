Morse Code Reference Chart

About Morse Code:

  • Morse code represents letters and numbers as sequences of dots (·) and dashes (−)
  • Each character is separated by a space
  • Words are separated by a forward slash (/)
  • Developed in the 1830s for telegraph communication
  • Still used in aviation, amateur radio, and emergency situations
